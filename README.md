# Student Result Analysis 📊

A simple Python mini-project built to practice data manipulation and visualization. I created this to strengthen my foundational data analysis skills, which ties in perfectly with my ongoing B.Tech CSE (AI & ML) studies. 

The script reads a dataset of student scores, calculates their basic statistics, and outputs easy-to-read charts.

## Features
* **Data Processing:** Built a Python program to parse and analyze student academic data from a CSV file.
* **Visualization:** Used Pandas and Matplotlib to generate performance visualizations (bar charts for subject averages, pie charts for pass/fail distribution).
* **Insights:** Performed basic statistical analysis on student performance, automatically calculating totals, percentages, and determining pass/fail status based on a 40% threshold.

## Technologies Used
* Python 3.10.x
* Pandas (for data manipulation)
* Matplotlib (for plotting and data visualization)

## Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/pushkarbiring/student-result-analysis.git
   cd student-result-analysis
   ```

2. **Install the required libraries:**
   Make sure you have Python installed, then run:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the script:**
   ```bash
   python analysis.py
   ```
